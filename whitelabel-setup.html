Reads /tenants/<folder>/tenant.json for the brand and copy, and /tenants/<folder>/products.json for the catalogue. Both are repo files, so what you publish is what is in version control.

2 · The catalogue

A manufacturer sends a spreadsheet. Convert it once with node scripts/import-products.js --org <org> --file their.csv --out tenants/<folder>/products.json — that script owns the column mapping, the unit conversion and the footprint sanity check, and it is the only place any of that logic lives. Pasting here skips those checks, so paste only something that script produced.
