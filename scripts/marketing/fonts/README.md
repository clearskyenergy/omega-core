# Fonts for the post graphics

Latin subsets from Google Fonts, used only by `scripts/marketing/card.js`
to render LinkedIn graphics. Never deployed (`scripts/` is ignored by Vercel).

| File | Family | Licence |
|---|---|---|
| `Archivo.woff2` | Archivo (variable weight) | SIL Open Font License 1.1 |
| `Inter.woff2` | Inter (variable weight) | SIL Open Font License 1.1 |
| `IBMPlexMono.woff2` | IBM Plex Mono 500 | SIL Open Font License 1.1 |

The same three families the marketing site (www.clearskyomega.com) uses.
