## Repeatable checks

- `node scripts/tests/tdesignorder.js`: saved project address, conflicting address
  refusal, no invented customer/account, estimate only, same order on resend,
  OEM routing, project/name/address/line preservation into the plant projection.
- `node scripts/test-order-lifecycle.js`: shipping reads the design order's canonical
  project ID, address and quantities; another tenant is refused; existing shipment
  transition, receiving and concurrency checks remain in place.
- `node scripts/render-logic-pages.js --journey-only --shots /tmp/omega-journey`:
  Chromium follows one explicitly seeded example across Office, Plant, Shipping
  and Accounting. It checks forward/back link targets, shared journey bars,
  project name, saved site, quantities, JavaScript errors and phone overflow.
  It prints measured clicks for each page's inspection (0, 1, 0, 1).
- `node scripts/render-logic-pages.js`: the full office/plant/portal browser suite,
  including shipment, receiving, custody and accounting interactions.
- `node scripts/render-dashboard.js`: signed-in tenant dashboard scenarios.
- `npm test`: unit, geometry, authorization and workflow regression checks.

Use `PLAYWRIGHT` and `CHROME` to select an installed browser for render checks.
The scripts otherwise may report a skip; a skip is not a pass.

## What this proves, and what it does not

Browser tests use synthetic fixture data and mocked Firebase authentication.
The journey begins with a document generated by the production design-order
library; invoice and production state are explicitly seeded. This is not a
live purchase, a bank-cleared payment, an actual carrier booking, or an
uninterrupted browser transaction through every external service.
Tenant refusal is separately exercised at the endpoint boundary in the API
regression tests. Firestore rules are unchanged.

Before production approval, exercise the protected preview with authorized test
accounts and a dedicated example project. Confirm the designer's real customer
account before pricing/billing; the designer is no longer silently made the buyer.
